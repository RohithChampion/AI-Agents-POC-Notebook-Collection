# 🧠 AI Agents – POC Notebook Collection

This repository contains a curated collection of notebooks that I created while **learning, experimenting, and practicing AI Agentic workflows** over the last few months.  
The goal of this repo is not to present a single project, but to demonstrate **hands-on exploration of key GenAI and Agent concepts** through small, focused Proof-of-Concepts (POCs).

Each notebook is independent and designed for:
- quick experimentation
- easier debugging
- understanding concepts in isolation before combining them

---

## 🚀 What this repository covers

The notebooks explore a wide range of topics, including:

### 🧩 Core Agentic & LLM Concepts
- different types of **prompting techniques**
  - zero-shot / few-shot prompting
  - chain-of-thought
  - self-consistency
  - ReAct style prompting
- working with **LLMs, tokens and context windows**
- fundamentals of **transformer architecture**
- using **function/tool calling** in agents
- implementing **memory in agents** (short-term and long-term)

---

### 🔍 Retrieval-Augmented Generation (RAG)

Practical implementations of RAG including:

- indexing custom documents
- building **vector databases**
- chunking and embedding strategies
- query transformation and reranking
- latency vs accuracy trade-offs
- evaluation of RAG pipelines using **RAGAS**

Vector stores experimented with:
- FAISS
- Chroma
- others depending on notebook context

---

### 🛠️ Agent Frameworks and Ecosystem

Hands-on notebooks using:

- **LangChain**
- **LangGraph** (graph-based agent orchestration)
- **LangSmith** for tracing and observability
- tools, retrievers and chains
- multi-agent communication patterns

Experiments include:
- tool-using agents
- multi-step reasoning
- multi-agent collaboration
- structured output generation

---

### 🧪 Evaluation & Observability

This repository also includes work on:

- tracing agent runs using **LangSmith**
- evaluating RAG pipelines using **RAGAS**
- understanding quality metrics such as:
  - faithfulness
  - answer relevance
  - context relevance
  - hallucination detection

---

### 🧬 Fine-Tuning & Model Training

Notebooks also cover:

- fundamentals of transformer model internals
- parameter-efficient fine-tuning using **LoRA**
- comparing base vs fine-tuned model outputs
- practical tuning considerations like:
  - overfitting
  - prompt sensitivity
  - dataset quality

---

### 📊 App Development – Streamlit

As part of this learning journey, I also built a **Streamlit application in the data domain**, integrating:

- LLMs
- RAG pipeline
- agent tools
- user-driven query workflows

This helped connect concepts to **real-world, end-to-end usage**.
